Discrete time Markov chains

Definition 2. For a state space \(\sX \subseteq \R\) and the random sequence \(X: \Omega \to \sX^{\Z_+}\), we define the history until time \(n \in \Z_+\) as \(\sF_n \triangleq \sigma(X_1, \dots, X_n)\).

Remark 2. Recall that the event space \(\sF_n\) is generated by the historical events \(A_X(x) \triangleq \cap_{i=0}^n\set{X_i \le x_i}\) where \(x \in \R^{n+1}\).

Remark 3. When the state space \(\sX\) is countable, the event space \(\sF_n\) is generated by the historical events \(H_n(x) \triangleq \cap_{i=0}^n\set{X_i = x_i}\), where \(x \in \sX^{n+1}\). That is, \(\sF_n = \sigma(H_n(x):x \in \sX^{n+1})\)

Definition 3. For a countable set \(\sX\), a discrete-valued random sequence \(X: \Omega \to \sX^{\Z_+}\) is called a discrete time Markov chain (DTMC) if for all positive integers \(n \in \Z_+\), all states \(x,y \in \sX\), and any historical event \(H_{n-1} = \cap_{m=0}^{n-1}\set{X_m = x_m} \in \sF_n\) for \((x_0, \dots, x_{n-1}) \in \sX^{n}\), the process \(X\) satisfies the Markov property

Remark 4. The above definition is equivalent to \(P(\set{X_{n+1} \le x}\given \sF_n) = P(\set{X_{n+1} \le x}\given \sigma(X_n))\) for discrete time discrete state space Markov chain \(X\), since \(\sF_n = \sigma(H_n(x): x \in \sX^n)\) and \(\sigma(X_n) = \sigma(\set{X_n = x}, x \in \sX)\).

Transition probability matrix

Definition 5. We denote the set of all probability mass functions over a countable state space \(\sX\) by \(\cM(\sX)\triangleq \set{\nu \in [0,1]^\sX: \sum_{x\in \sX}\nu_x = 1}.\)

Definition 6. The transition probability matrix at time \(n\) is denoted by \(P(n) \in [0,1]^{\sX \times \sX}\), such that its \((x,y)\)th entry is denoted by \(p_{xy}(n) \triangleq P(\set{X_{n+1} = y}\given\set{X_n = x})\), that is the transition probability of a discrete time Markov chain \(X\) from a state \(x \in \sX\) at time \(n\) to state \(y \in \sX\) at time \(n+1\).

Remark 5. We observe that each row \(P_{x}(n) \triangleq (p_{xy}(n): y \in \sX) \in\cM(\sX)\) is the conditional distribution of \(X_{n+1}\) given the event \(\set{X_n = x}\).

Definition 7. A matrix \(A \in \R_+^{\sX \times \sX}\) with non-negative entries is called sub-stochastic if the row-sum \(\sum_{y \in \sX} a_{xy} \le 1\) for all rows \(x \in \sX\). If the above property holds with equality for all rows, then it is called a stochastic matrix. If matrices \(A\) and \(A^T\) are both stochastic, then the matrix \(A\) is called doubly stochastic.

Remark 6. We make the following observations for the stochastic matrices.

Every probability transition matrix \(P(n)\) is a stochastic matrix.

All the entries of a sub-stochastic matrix lie in \([0,1]\).

Each row \(A_x \triangleq (a_{xy}: y \in \sX)\) of the stochastic matrix \(A \in \R_+^{\sX \times \sX}\) belongs to \(\cM(\sX)\).

Every finite stochastic matrix has a right eigenvector with unit eigenvalue. This can be observed by taking \(\bU^T = \begin{bmatrix}1 & \dots & 1\end{bmatrix}\) to be an all-one vector of length \(\abs{\sX}\). Then we see that \(A \bU = \bU\), since

Every finite doubly stochastic matrix has a left and right eigenvector with unit eigenvalue. This follows from the fact that finite stochastic matrices \(A\) and \(A^T\) have a common right eigenvector \(\bU\). It follows that \(A\) has a left eigenvector \(\bU^T\).

For a probability transition matrix \(P(n)\), we have \(\sum_{y \in \sX}f(y)p_{xy}(n) = \E[f(X_{n+1})\mid\set{X_n =x}].\)

Homogeneous Markov chains

In general, not much can be said about Markov chains with index dependent transition probabilities. We consider the simpler case where the transition probabilities \(p_{xy}(n)= p_{xy}\) are independent of the index.

Definition 8. A discrete time Markov chain with the probability transition matrix \(P(n)\) that is independent of the index, is called time homogeneous.

Example 9 (Integer random walk). For a one-dimensional integer valued random walk \(S: \Omega \to \Z^\N\) with unit step size sequence \(X: \Omega \to \set{-1,1}^\N\) such that \(P\set{X_1 = 1} = p\), the transition operator \(P \in [0,1]^{\Z\times\Z}\) is given by the entries \(p_{xy} = p\indicator{y=x+1}+(1-p)\indicator{y=x-1}\) for all \(x,y \in\Z\).

Proof. Proof. It follows from summing over all possible paths \((X_0, \dots, X_n)\) and \((X_m, \dots, X_{m+n})\). Random mapping theorem

We saw some example of Markov processes where \(X_n = X_{n-1} + Z_n\), and \(Z:\Omega\to\Lambda^\N\) is an sequence, independent of the initial state \(X_0\). We will show that any discrete time Markov chain is of this form, where the sum is replaced by arbitrary functions.

Theorem 16 (Random mapping theorem). For any DTMC \(X:\Omega\to\sX^{\Z_+}\), there exists an sequence \(Z \in \Lambda^\N\) and functions \(f_n: \sX \times \Lambda \to \sX\) such that \(X_{n} = f_n(X_{n-1}, Z_{n})\) for all \(n \in \N\).
