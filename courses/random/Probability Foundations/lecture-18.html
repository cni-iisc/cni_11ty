Stopping times

Let (\Omega, \sF, P) be a probability space. Consider a random process X:\Omega\to\sX^T defined on this probability space with state space \sX \subseteq \R and ordered index set T\subseteq \R considered as time.

Definition 1. A collection of event spaces denoted \sG_{\bullet} \triangleq (\sG_t \subseteq \sF: t \in T) is called a filtration if \sG_s \subseteq \sG_t for all s \le t.

Remark 1. For the random process X:\Omega\to\sX^T, we can find the event space generated by all random variables until time t as \sF_t\triangleq \sigma(X_s, s \le t). The collection of event spaces \sF_\bullet \triangleq (\sF_t: t \in T) is a filtration.

Definition 2. The natural filtration associated with a random process X:\Omega \to \sX^T is given by \sF_\bullet \triangleq (\sF_t: t\in T) where \sF_t \triangleq \sigma(X_s, s\le t).

Remark 2. For a random sequence X: \Omega \to \sX^\N, the natural filtration is a sequence \sF_\bullet = (\sF_n: n \in \N) of event spaces \sF_n \triangleq \sigma(X_1, \dots, X_n) for all n \in \N.

Remark 3. If the random sequence X is independent, then the random sequence (X_{n+j}: j \in \N) is independent of the event space \sigma(X_1, \dots, X_n).

Example 3. For a random walk S with step size sequence X, the natural filtration of the random walk is identical to that of the step size sequence. That is, \sigma(S_1, \dots, S_n) = \sigma(X_1, \dots, X_n) for all n \in \N. This follows from the fact that for all n \in \N, we can can write S_j = \sum_{i=1}^jX_i and X_j = S_j - S_{j-1} for all j \in [n]. That is, there is a bijection between (X_1, \dots, X_n) and (S_1, \dots, S_n).

Definition 4. A random variable \tau: \Omega \to T is called a stopping time with respect to a filtration \sF_\bullet if

  1. the event \tau^{-1}(-\infty, t] \in \sF_t for all t \in T, and

  2. the random variable \tau is finite almost surely, i.e. P\set{\tau < \infty} = 1.

Remark 4. Intuitively, if we observe the process X sequentially, then the event \set{\tau \le t} can be completely determined by the observation (X_s, s \le t) until time t. The intuition behind a stopping time is that its realization is determined by the past and present events but not by future events. That is, given the history of the process until time t, we can tell whether the stopping time is less than or equal to t or not. In particular, \E[\SetIn{\tau \le t}\given \sF_t]=\SetIn{\tau \le t} is either one or zero.

Definition 5 (First hitting time). For a process X:\Omega\to\sX^T and any Borel measurable set A \in \sB(\sX), we define the first hitting time \tau_X^A: \Omega \to T\cup\set{\infty} for the process X to hit states in A, as \tau_X^A \triangleq \inf\set{t \in T: X_t \in A}.

Example 6. We observe that the event \set{\tau_X^A \le t} = \set{X_s \in A \text{ for some }s \le t} \in\sF_t for all t \in T. It follows that, if \tau_A is finite almost surely, then \tau_A is a stopping time with respect to filtration \sF_\bullet.

Proposition 7. For a random sequence X: \Omega \to \sX^\N, an almost sure finite discrete random variable \tau: \Omega \to \N\cup\set{\infty} is a stopping time with respect to this random sequence X iff the event \set{\tau = n} \in \sigma(X_1, \dots, X_n) for all n \in \N.

Proof. Proof. From Definition [defn:StoppingTimeGen], we have \set{\tau = n} = \set{\tau \le n}\setminus\set{\tau \le n-1} \in \sigma(X_1, \dots, X_n). Conversely, from the theorem hypothesis, it follows that \set{\tau \le n} = \cup_{m=1}^n\set{\tau = m} \in \sigma(X_1, \dots, X_n). ◻

Example 8. Consider a random sequence X: \Omega \to \sX^\N, with the natural filtration \sF_\bullet, and a measurable set A \in \sB(\sX). If the first hitting time \tau_X^A:\Omega\to\N\cup\set{\infty} for the sequence X to hit set A is almost surely finite, then \tau_X^A is a stopping time. This follows from the fact that \set{\tau_X^A = n} = \cap_{k=1}^{n-1}\set{X_k \notin A}\cap\set{X_n \in A} \in \sF_n for each n \in \N.
